# Proposal：缺失证据驱动的手术视频主动观察

**暂定英文题目：Evidence-Deficit-Guided Active Observation for Reliable Surgical Video Assessment**

状态：研究提案，尚未实现或获得实验结果。更新日期：2026-09-08。

定位：以 CVS 视觉评估为起点，在固定观察预算内根据缺失证据选择补看动作，减少错误肯定。主 benchmark 为正式发表于 Scientific Data 2025 的 Endoscapes，MedVidBench 用于现有代码诊断与任务迁移。

## 1. Introduction

手术视频理解需要识别细微解剖结构、空间关系及其随操作发生的变化。即使模型具备相关知识，它在低分辨率、遮挡或不合适视角下也可能无法获得判断所需的信息。此时，继续生成解释不一定能改善判断，系统需要决定是否值得获取更多视觉材料，以及应该如何获取。

Critical View of Safety（CVS）提供了一个具体而可评价的研究入口。现有公开数据为若干视觉条件提供专家标注，使研究能够从开放式手术问答收敛到明确的条件级判断。[Endoscapes 数据论文](https://www.nature.com/articles/s41597-025-04642-4)同时强调标注分歧和类别不平衡，为研究观察不足与错误肯定提供了现实背景。

专家检查清单已经被用于 CVS 评估，因此本文不把条件分解作为主要创新。我们进一步提出：**不同证据缺口需要不同观察动作，并非所有不确定样本都值得以相同方式补看。** 例如，图像细节不足可能受益于高分辨率观察，而结构遮挡可能需要邻近历史视角。也存在补看无效、应保留不确定性的情况。

本文拟研究三项问题：

1. 固定预算下，错误判断中有多少可以通过增加视觉证据修复？
2. 有效补看动作是否因当前证据缺口而异，能否从模型可见状态预测？
3. 相比固定补看、重复回答和已有结构化检查，主动选择能否降低错误肯定，并保持有用的覆盖率与敏感度？

预期贡献包括观察动作的受控修复性分析、一个轻量的证据缺口到动作选择器，以及条件级可靠性与成本评测。目标是公开数据上的视觉评估，不将 CVS 预测解释为临床操作许可或患者结局改善。

与 [Evolving Video Agent](../evolving_video_agent/main.md) 的边界是固定 Agent skill、经验 memory 和模型权重，研究单个病例中的证据获取。如果训练轻量选择器，只学习动作的条件收益，不进行跨样本语言反思或技能进化。

## 2. Related work

### 2.1 医学视频 benchmark 与结构化推理

[MedGRPO，CVPR 2026](https://uii-ai.github.io/MedGRPO/)与 MedVidBench 覆盖多个医学视频任务，适合复用任务适配，但整体均分不能直接支持可靠性结论。[Endoscapes](https://www.nature.com/articles/s41597-025-04642-4)提供 CVS 和部分解剖空间标注，适合开展条件级分析。

[Sum-of-Checks](https://arxiv.org/html/2604.22156v1)已经使用专家定义的检查项组织 CVS 推理，并分析观察可靠性与解剖证据的差异。本文将其作为直接强基线，研究给定检查结果之后，额外观察如何分配。仅更换 prompt、增加子问题或添加解释，不构成本文预期贡献。

### 2.2 视频主动观察与时间信息

[VideoSeek](https://arxiv.org/abs/2603.20185)、[Deep Video Discovery](https://arxiv.org/abs/2505.18079)和 [LensWalk](https://arxiv.org/abs/2603.24558)提供主动取证或动态观察的思路。手术场景中，[近期 CVS 时序建模研究](https://link.springer.com/article/10.1007/s11548-026-03748-3)也已利用时间信息。

本文不能把多帧观察本身作为新意，而要证明条件化动作选择优于最好的固定观察策略。时间信息只为固定评估时刻提供背景，历史帧中的条件成立不等于当前帧成立。

### 2.3 视觉依赖与可修复性

[SurgCheck](https://ailab-kyunghee.github.io/SurgCheck/)指出部分手术 VQA 可利用语言捷径，支持使用不看图和语言偏置对照。[CARVE 的回放审计](https://arxiv.org/abs/2608.15685)强调对视觉扰动敏感不等于错误可修复，因此本研究直接比较动作前后的任务误差，并设置不增加视觉信息的重复回答对照。

| 最近邻 | 已有贡献 | 本研究的边界 |
|---|---|---|
| Sum-of-Checks | 专家条件分解与证据检查 | 基于检查缺口选择有收益的额外观察 |
| 固定多帧、时序模型 | 利用邻近上下文改善判断 | 相同预算下按状态选择分辨率、区域或历史视角 |
| 通用主动视频 Agent | 按问题调用视频工具 | 可预测的修复收益和错误肯定控制，而非通用准确率 |
| Evolving Video Agent | 跨样本反馈更新技能和经验 | 冻结 Agent，研究病例内观察决策 |

## 3. Method

### 3.1 固定评估对象，避免标签漂移

主任务输入为一个带 CVS 标注的目标帧 x_t 及其可用历史上下文。输出始终对应时刻 t 的三个条件，不把任务改成视频中曾经出现过 CVS。初始观察使用目标帧的低成本版本，后续允许访问该帧的高分辨率视图或有限历史窗口。

主协议仅使用 t 及之前的信息。第一版历史窗口设为最近 10 秒，具体长度在验证集固定。所有方法使用同一窗口。后续若研究离线双向上下文，必须单列实验，不能与因果设置混报。

官方 CVS 标签是三名标注者判断的均值，存在离散小数值。主指标沿用官方评测代码的标签处理，不未经核实把它们转换成整数分数。可靠性诊断额外区分一致同意、一致否定和分歧样本，分歧不能被直接标成不可观测。

### 3.2 当前证据状态

使用固定检查项获取三个条件的初始评分及可观测缺口，例如分辨率不足、可见区域受遮挡、关键关系不明确。检查项优先复用公开 Sum-of-Checks 定义，避免起步阶段重新设计医学标准。

证据状态包括检查预测、评分间隔、已看图像的清晰度、已执行动作与剩余预算。所有字段来自实际观测与模型预测，不能读取当前标签、专家分歧或真值解剖框作为推理输入。

### 3.3 小动作集合与预算

| 动作 | 可获得的新信息 | 第一版约束 |
|---|---|---|
| STOP | 不再获取信息 | 保留当前预测或按校准阈值拒答 |
| DETAIL | 目标帧更高分辨率 | 使用原图，不使用生成式超分辨率 |
| REGION | 目标帧预测区域的细看 | 区域来自模型预测，不能使用真值框；保留全图上下文 |
| HISTORY | 目标时刻之前的其他视角 | 从固定窗口取最多 2 张帧，随后返回目标帧核验 |

最小原型先启用 STOP、DETAIL、HISTORY，REGION 在 ROI 定位可稳定运行后增加。固定初始调用，最多两轮补看和一次最终判断。由于不同动作图像数量和分辨率不同，既报告调用数，也报告视觉 token/像素量与实测延迟。成本相差较大的动作需在匹配预算下比较。

HISTORY 不能访问未来画面。将历史条件视作当前成立是专门需要统计的失败类型。最终判断必须重新对照目标帧，不允许从多个时刻各取一个满足条件的画面拼成整体肯定。

### 3.4 从证据缺口预测动作收益

先用固定规则实现基线，再用训练病例上的分支回放构建轻量监督：从同一初始状态分别执行可用动作，观察任务损失的变化。

\[
u(a,s)=L(y,\hat y_{\mathrm{before}})-L(y,\hat y_{\mathrm{after},a})-\lambda C(a).
\]

L 可以在开发阶段设为条件级加权分类损失，对错误肯定赋予预先确定的较高权重。权重与阈值不得依据测试表现调节。C 是动作的完整增量成本。收益允许为负，补看将正确答案改错同样计入。

使用逻辑回归或浅层树预测每个动作的收益，选择预计收益最高的动作；若没有正收益则停止。第一阶段先研究单轮选择，多轮只有在单轮有效后开展，并对更新状态重新估计收益。

对随机性设置相同输入的 REANSWER 对照，并对训练子集重复采样，区分新视觉信息与再次生成带来的变化。知道真值后挑最佳动作的 oracle 仅估计上界，不作为可部署方法。

### 3.5 输出与 VideoSpy 复用

输出条件级预测、目标帧时间、引用图像、未解决的缺口以及回答/拒答标记。引用首先保证来源可追踪，其医学充分性需另行评价。

复用 `videospy/agent.py` 的工具循环、`frame_inspect` 的图像读取和 `benchmark/medvidbench/run.py` 的任务格式。`clip_skim` 当前低分辨率观察适合初始诊断，不能直接承担精细解剖核验。新增一个小型动作选择器、Endoscapes 帧序列适配和条件级评测即可启动，不需要重写 Agent 或训练专用大模型。

## 4. 实验设计

### 4.1 Benchmark 规模与优先级

| Benchmark | 正式发表情况 | 数据规模 | 选择理由与限制 |
|---|---|---|---|
| **Endoscapes-CVS201，主评测** | Scientific Data 2025；配套官方划分技术报告为 2023 预印本 | 201 台手术，11,090 个 CVS 标注帧；相关区域共 58,813 张 1 fps 图像 | 规模适中，专家标签可用。官方按手术划分为训练 120、验证 41、测试 40 台 |
| Endoscapes-BBox201 / Seg50，辅助诊断 | 同一已发表数据集的空间标注子集 | BBox：1,933 帧、201 台手术；公开 Seg50：493 帧、50 台手术 | 辅助验证区域定位，不能当成独立数据集或默认每帧都有充分性标注 |
| **MedVidBench，迁移评测** | MedGRPO，CVPR 2026 | 当前官方测试发布 6,245 样本，CVS 648 题；总计 103,742 帧，约 18 GB | 可复用现有 runner，但测试答案在评测服务器，不能依赖它训练选择器 |
| 当前本地 MedVidU TrainVal，启动诊断 | 挑战赛发布版本，不能等同于上述论文官方测试集 | 本地核对共 6,270 样本，其中 CVS 600；当前全任务 train/test manifest 为 5,146/1,124 | 可快速诊断，CVS 子集及原始手术划分仍须单独核查 |

来源：[Endoscapes 正式数据论文](https://www.nature.com/articles/s41597-025-04642-4)、[官方仓库的标注与划分](https://github.com/CAMMA-public/Endoscapes)、[MedVidBench 官方数据卡](https://huggingface.co/datasets/UII-AI/MedVidBench)。本地数量于 2026-09-08 从 QA 文件及 manifest 只读统计，600 与官方测试的 648 不混用。

Endoscapes 的 CVS 每 5 秒标注一次，相关图像以 1 fps 提供。58,813 秒约为 16.3 小时采样区间量级，这是按帧数换算的工作量估计，不是完整手术总时长。直接使用已提取帧可避免下载和解码全部手术视频。原始数据的 [PhysioNet 发布入口](https://physionet.org/content/endoscapes-2023/1.0.0/)需要注册并签署使用协议，下载前核实实际入口与条款。

不把 JIGSAWS 技能评分、自由摘要或下一步动作作为首轮主任务，因为其证据充分性更难用当前标签客观验证。若主方法有效，再考虑 MedVidBench 中具有明确时间或空间标签的任务迁移。

### 4.2 数据划分与标签审计

Endoscapes 严格使用官方 120/41/40 台手术划分。训练选择器只使用训练病例；动作规则、损失权重、停止和拒答阈值在验证病例确定；最终评测覆盖全部测试病例的合格标注帧，不按帧随机划分。

每帧的三个条件名与数据标签顺序逐项核对。MedVidBench 当前输出是 0–2 分数，不能未经生成规则核实直接映射到 Endoscapes 的标注均值。两者若无法可靠映射，就分别按各自官方任务评分。

Endoscapes 与 MedVidBench 的 CVS 来源可能重叠。迁移实验需按原始手术 ID、时间段或可用帧指纹检查重叠。重叠时只能称为任务格式迁移，不能称为独立外部泛化。Endoscapes 是单中心数据，不能由此推断跨医院可靠性。

### 4.3 最小诊断实验

从官方训练集约 20 台手术抽取 200–300 个目标帧，兼顾不同条件和分歧程度。该富集子集只用于找问题，不替代按自然分布的最终评测。

固定初始预测，分别执行 STOP、REANSWER、DETAIL、HISTORY。首先判断补看是否比重复回答更有效，再检查不同样本的最佳动作是否不同。如果最佳固定动作几乎解释全部增益，则不开发复杂选择器。

之后从训练病例扩大分支数据，训练轻量选择器。保持同一目标帧、检查项和最终回答模型，隔离动作本身的作用。REGION 在不使用真值框的条件下单独验证，不能让标注泄漏掩盖 ROI 选择难度。

### 4.4 强基线与消融

主基线为直接判断、Sum-of-Checks、原始 VideoSpy、固定高分辨率、固定历史多帧、随机动作、基于置信度的补看，以及所提证据缺口选择器。主比较使用同一底座与相同预算，同时给出无需 Agent 的专用 CVS 模型作为任务参照，披露其监督与训练成本。

关键消融包括去掉证据缺口、只用置信度、去掉动作成本、去掉错误肯定权重、只允许单种观察，以及无额外图像的重答。参数更多的选择器只能在浅层方法无法表达有效规律时考虑。

### 4.5 指标与高可信主张的边界

主任务报告每个条件 AP 与 mAP，并沿用官方标签处理。可靠性部分采用预先声明的二值化或一致标注子集，报告：

- 假阳性率 `FP/(FP+TN)` 与肯定预测中的错误比例 `FP/(TP+FP)`，二者不能混称。
- 固定敏感度下的误报率，以及风险随回答覆盖率变化的曲线。
- 每个动作的纠错率、改错率、净收益与成本。
- 一致标注与专家分歧样本的分层结果。
- 按手术聚类的置信区间、不同底座下的稳定性。

低错误率不能通过几乎全部拒答或全部否定获得，必须同时报告覆盖率、敏感度和阳性预测数量。校准集与评测集按手术隔离，少量高度相关帧不能支持分布无关风险保证。

证据评价分三级：来源与时间合法性可以自动检查，预测区域与空间标注的对应可在有标注帧上检查，临床证据充分性需要专家审核。前两项不能替代第三项。建议在结果稳定后对 100 个分层病例片段进行盲审，由两名专家独立评价引用是否支持该条件、历史信息是否被误用于当前判断，并记录分歧。这是新增标注计划，现阶段不声称已经具备。

若无外科合作，仍可完成标签级准确率、补看收益和错误肯定研究，但论文主张限定为数据集上的可靠视觉评估，不扩展为临床安全保证。

### 4.6 可行性与预算

从一个冻结 7B/8B 级模型或现成推理服务启动，不做端到端训练。轻量选择器的成本主要来自分支回放，而非拟合本身。

以 300 个目标状态、4 个分支、2 次重复为例，需要 2,400 次分支试验，另加初始状态构建。最终完整测试的目标数由官方下载后的 annotation 文件统计确定。若按约 2,000 个目标帧、6 种方法、每题最多 4 次调用估算，单预算档上限约 48,000 次调用，多预算和第二底座另计。先跑 20 个状态测吞吐与费用，再调整评测顺序。

| 阶段 | 预计工作量 | 通过条件 |
|---|---|---|
| 数据与标签核对 | 2–3 个工作日，不含审批等待 | 确认原始帧、条件映射、病例划分与重叠情况 |
| 动作修复性诊断 | 4–7 个工作日 | 新证据优于重答，且存在不同动作的稳定收益差异 |
| 选择器与消融 | 约 1 周 | 超过最佳固定动作、置信度补看和 Sum-of-Checks |
| 完整评测与审核 | 1–2 周起 | 正式测试、第二底座和专家抽查支持主要结论 |

时间估计以一位熟悉代码的研究者、可用推理服务为前提，专家审查单独安排。若主要错误来自模型无法识别解剖结构，且补看不能修复，则停止该策略方向，不能通过增加 Agent 轮数掩盖感知瓶颈。

## 5. 结论

本提案以体量适中、正式发表且具有专家标签的 Endoscapes 为主 benchmark，把手术视频 Agent 收敛为缺失证据驱动的主动观察。预期方法增量是学习何时补看、补看什么及何时停止，需在相同预算下超越已有检查清单与固定多帧策略。

现有 VideoSpy 可以支持低成本原型，最大不确定性是错误是否可通过观察修复，以及原始标签能支持多强的证据结论。第一步应完成受控诊断，再决定投入选择器、跨模型实验与专家审核。当前提案不包含已经实现的性能或临床效果结论。
