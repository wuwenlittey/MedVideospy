**二、现有项目给了什么，缺什么**

当前实现已有三个视觉工具、完整消息和内部模型调用记录、Task/Domain Skill、事实与推理案例 Memory、评分和审核、SQLite 版本管理、多个 benchmark 适配。这些是开展机制研究的实验底座。

当前主流程是读取已有推理轨迹，再离线蒸馏 Skill 与 Memory；不会因为本轮 Skill 改变而自动生成下一轮训练轨迹，也不更新模型权重。已有模型审核不等于在真实任务上测得更新收益。后续研究的关键增量可以是：可控干预、新策略 rollout、参数学习，或者可靠的证据充分性评价。

**四、P1：由真实观察收益驱动的视频 Agent 自进化**

暂定英文题目：**Intervention-Grounded Evolution of Video Agents**。

研究问题：一条轨迹答错，可能是没有看对片段、看到了但描述错了、描述正确却推理错了。仅让 Reflector 阅读轨迹，未必能区分这些情况。能否通过少量真实观察干预，找到能修复错误的操作，再把它们变成可迁移 Skill？

核心假设：在相同历史和相同成本条件下，动作的实际增益，比一次语言反思产生的“建议”更适合指导跨任务进化。

拟议方法：

1. 保存决策前缀 h：问题、已经返回的观察、已用预算、已有 Skill。选择值得审计的决策点。
2. 从同一个 h 分出若干真实动作：保持原动作、重复原样执行、检查邻近时间、提高观察细度、提前停止。动作来自现有三个工具；不通过改写 caption 假装观察过新视频。
3. 每个分支执行真实工具并重新生成后续轨迹，不能把旧轨迹中依赖旧观察的推理直接接上去。用配对运行估计答案与证据收益，并扣除额外观察成本。
4. 区分“信息变化带来的增益”和“多采样／重答带来的增益”。对预算相近的无新增证据分支也做对照。
5. 将有重复支持的状态—动作模式提炼成带适用条件的 Skill，在未参与提炼的开发视频上实测；收益不稳定的规则不发布。
6. 更新后的 Agent 重新生成下一轮训练轨迹，形成真正的执行—学习闭环。

一个可操作的目标是 Delta(h,a) = E[J(rollout(h,a)) - J(rollout(h,a_base))]，其中 J 同时报告正确性、证据质量与成本。权重在开发集固定，不能为了每个方法各自调到最好。这里估计的是固定实验条件下改变 Agent 动作的效果，不是医学事件的因果效应，也不主张精确计算了每步的全局因果贡献。

与近邻的区别：SkillCAT 已做候选技能回放，CTA 已做有无 Skill 的轨迹对齐；本提案需要证明**同一观察前缀下的动作级干预**能提供额外价值。CARVE 已说明破坏证据的敏感度并不稳定等价于修复收益，因此方法不能只删除关键帧后看答案是否变化。[SkillCAT](https://arxiv.org/abs/2606.13317)、[CTA](https://arxiv.org/abs/2605.11946)、[CARVE](https://arxiv.org/abs/2608.15685)。

最小实验：先在合法训练／开发划分内选约 100–200 道有时间证据的题，包含答错和答对但证据不足的情况。做固定补看、随机补看、纯重答、语言反思推荐动作、干预收益推荐动作五组比较。该规模用于诊断，不能自动视为足够的显著性实验。

主实验：LVBench 等通用视频，加一个医学长视频域；固定总训练调用预算、推理观察预算和基础模型。比较当前 VideoSpy-Evolve、ACE/GEPA 式上下文优化、SkillCAT 式对比回放，以及去掉真实分支执行的版本。若不能原样复现某基线，要标注为统一工具下的适配实现。

关键指标：准确率—总成本曲线、错误修复率、正确答案被破坏的比例、证据命中与精度、Skill 在新视频／新模型上的收益、跨轮次回退。以视频为独立单位做置信区间，不能把同一视频多个问题当完全独立样本。

值得继续的信号：不同前缀的最优补看动作确实不同，且这种差异能从推理时可见状态预测；学得规则能在新视频上超过最佳固定观察策略。若增益完全来自多调用模型，或只对产生规则的题有效，应停止包装成自进化方法。

复用度高；首先新增轨迹分支和真实回放，不必立刻训练大模型。主要风险是分支成本以及工具模型的随机性。可缓存完全相同配置和输入的工具输出来做第一阶段实验，但正式报告需区分缓存条件与真实重复调用条件。

**五、P2：学习应该在哪里适配——Skill、决策模型还是视觉工具**

暂定英文题目：**Learning Where to Adapt: Budgeted Co-Evolution of Video Agent Policies and Skills**。

研究问题：面对新任务或新医学术式，Agent 答错后应该修改提示经验、更新决策模型，还是补强视觉感知？始终更新所有组件代价大，也容易把偶然事实固化到参数里。

核心假设：失败类型和知识的迁移范围决定合适的适配位置；在固定适配预算下，学会选择更新位置，比固定周期的“Skill + LoRA”更有效。

拟议方法：先通过小规模受控诊断建立几种适配操作的收益数据。例如，换正确观察后能否恢复、保持观察但换推理器能否恢复、加入一般策略后是否恢复。训练一个轻量选择器，在新任务批次到来时选择不更新、更新 Skill、更新决策模型，或者在第二阶段才开放的视觉工具适配。训练奖励来自独立开发样本上的迁移收益，扣除训练和检索成本，并惩罚旧任务遗忘。

经验存储采用明确边界：病例事实留在来源受限的 Memory；跨病例有效但尚不稳定的规则留在可撤回 Skill；多轮验证稳定的程序性操作才进入参数训练候选。第一版仅比较“不更新／Skill／决策 LoRA”，避免三类大模型一起训练造成归因困难。视觉工具适配先作为诊断上界，后续再加入。

直接近邻是 SEED 的 hindsight-skill 蒸馏、TMEM 的参数记忆，以及 MetaSkill-Evolve 的两层演化。新增贡献必须是**可学习的适配位置选择及其代价—迁移收益规律**，不是简单把它们串起来。[SEED](https://arxiv.org/abs/2607.14777)、[TMEM](https://arxiv.org/abs/2606.04536)、[MetaSkill-Evolve](https://arxiv.org/abs/2607.05297)。

实验：构造训练域 A→B→C→A 的序列，每一域内部保留未见过的视频测试集。至少比較固定 Skill 更新、固定 LoRA 更新、固定交替更新、随机操作选择、规则路由和学习路由；各方法匹配总适配算力与样本数。测试时是否继续学习必须事先固定，在线设置也不能读取未来任务和答案。

指标：平均学习曲线面积、适配成本、向前／向后迁移、旧任务遗忘、路由选择相对事后最优操作的差距。oracle 只作诊断上界，不能与可部署方法混称。

最小验证：先用两个域比较同一批错误在 Skill 与 LoRA 两种更新下的收益是否存在可预测差异。若一个操作始终占优，或者路由收益被诊断成本抵消，这一方向就不值得独立成篇。

这与仓库“模型和 harness 两条腿走路”的想法高度一致，但工程量明显大于 P1。它更适合作为有训练资源后的第二阶段，而非最先启动的项目。

**六、P3：观察条件匹配的医学视频轨迹蒸馏**

暂定英文题目：**Learning to Seek Medical Evidence: Observation-Matched Trajectory Distillation for Long-Video Agents**。

研究问题：强教师可以看完整视频、获得高质量工具描述，甚至在训练时拿到时间标注。直接模仿它的成功轨迹，学生可能学到无法根据当前观察推出的时间跳转，或依赖学生自己的视觉工具无法提供的描述。能否把教师能力转成学生在自身观察条件下可执行的证据搜索策略？

这里的“信息不匹配”是待测假设，不是已经证明 MedScope 或 LongVideo-R1 存在数据泄漏。训练时使用答案和时间标注作为监督是正常的；要区分合法的监督信号与要求学生模仿不可观测决策的学习问题。

拟议方法：

1. 从医学训练视频生成多条真实工具轨迹，保存每个决策前缀、工具参数、观察来源和返回内容。先训练沿用 VideoSpy 的小型决策模型，固定视觉工具，确保因果归因清楚。
2. 分离两个教师角色：动作教师只看到学生当前可见的历史；评分器可以使用训练答案和证据标注。后者用于判断轨迹质量，不把最终答案或尚未观察的帧描述塞进动作教师输入。
3. 在同一学生前缀下产生若干候选动作，真实执行并比较“是否找到新增相关证据、是否修复答案、花费多少”。学习工具、时间范围和停止选择，而不仅是长篇解释。
4. 先做轨迹 SFT，再用学生自己的 rollout 收集偏离状态，补充教师纠正。初期可做动作偏好学习；具备训练基础后再比较 on-policy 蒸馏或 RL。
5. 构造当前观察近似一致、后续证据不同的配对样本，检验学生是否先获取能区分答案的证据。配对样本若通过编辑构造，需单独报告，并排除剪辑痕迹成为捷径。
6. 第二阶段再更换为较弱或较强的医学视觉工具，检验策略是否依赖某一工具生成的措辞和错误模式。若做端到端 VLM 蒸馏，则恢复原始像素并单独标记实验。

创新必须落在：**动态可观测性约束下的动作监督，以及学生观察分布上的训练**。普通“强模型生成轨迹→筛成功→SFT→GRPO”与 MedScope、LongVideo-R1 重合。最近关于教师特权上下文的研究也提示，需要比单纯减少教师信息更完整的机制和实验证据。[MedScope](https://arxiv.org/abs/2602.13332)、[LongVideo-R1](https://arxiv.org/abs/2602.20913)、[What Should a Self-Teacher See?](https://arxiv.org/abs/2609.25623)。

一个值得进一步精读的具体边界：MedScope 正文中的 grounding reward 依据最终工具调用进行计算；本提案可研究整个多步证据获取过程，尤其多处证据都必须收集时的动作信用分配。但“给所有步骤加奖励”仍只是设计起点，需要证明它避免了什么明确失败。[MedScope 方法与附录](https://arxiv.org/html/2602.13332v1)。

数据建议：合法医学训练数据用于轨迹生成；SurgCoT 可提供跨术式与时空线索任务；MedHorizon 留作完整流程的外部测试。其公开版本仅有 test，不能拿来训练或反复调参。MedVidBench 用于现有接口验证和医学任务诊断，但必须核实本地 TrainVal 来源，不能把官方测试包当训练集。

必须做的对照：答案 SFT、普通成功轨迹 SFT、同规模且同 token 数的观察匹配 SFT、进一步加入学生 rollout 的版本、加入动作收益监督的版本，以及 grounding-aware RL。分开比较数据收集分布、教师视野和训练损失，避免同时改变三件事后无法归因。

关键指标：回答准确率、证据检索质量、多证据任务的完整收集率、成本、跨术式迁移、更换工具模型后的鲁棒性。再做 question-only、字幕／讲解单独输入、时间戳扰动、同观察前缀配对实验，检查是否只是记住手术常识或题目模板。

最小验证：约 200 道训练／开发题比较全信息教师与同观察教师的动作质量，再用约 1K 轨迹做小规模决策模型 LoRA。数量是试验设计建议，不是预计充分的数据量。必须以真实 rollout 而不是 teacher-forced token accuracy 判定是否有效。

继续条件：观察不匹配确实造成学生执行失败；在匹配数据与计算预算后，同观察／学生 rollout 训练能在未见术式或不同工具模型下稳定改善。如果普通轨迹 SFT 已同样有效，不能仅靠换成医学数据支撑顶会贡献。

**七、P4：医学视频的证据充分性与风险受控观察**

暂定英文题目：**Risk-Controlled Evidence Acquisition for Long Medical Videos**。

研究问题：医学视频中，“没看到”可能来自未搜索到、图像无法判断，或者当前片段确实不支持某个结论。Agent 应何时继续观察，何时回答，何时输出证据不足？

核心假设：显式区分证据覆盖与局部识别不确定性，并校准完整取证策略的错误风险，可以在有限预算内优于自报置信度和固定步数。

拟议方法：维护与问题绑定的证据状态，例如已检查的时间段、必要事件是否各自找到、视角是否足够、同一结论是否存在矛盾。用条件化收益模型选择下一次 clip_skim 或 frame_inspect，并学习停止／保留不确定性的选择。停止目标是回答有证据支撑，不是搜索到任意一个相关画面。

统计部分应先采用可审查的设置：训练并冻结整套检索与停止策略；在独立患者／视频校准集上校准端到端策略；最终测试也按患者／视频分组。若进一步声称任意时刻停止的风险保证，需要给出适用于自适应选择的额外方法和假设，不能把单次预测的 conformal 覆盖率直接套到任意轮次。

直接近邻：Conformal Thinking 已研究推理预算的风险控制，COVER 已研究时间定位区间覆盖；Sum-of-Checks 已用结构化检查开展手术评估。本提案要研究的是**多步主动视觉取证后，任务结论的证据充分性与成本**，而不是简单加检查清单或置信度阈值。[Conformal Thinking](https://arxiv.org/abs/2602.03814)、[COVER](https://arxiv.org/abs/2608.07434)、[Sum-of-Checks](https://arxiv.org/abs/2604.22156)。

与已有项目规划的关系：已有手术 proposal 聚焦 CVS 条件级观察和修复性。本方案可从那里开始，但若主张“长视频理解”，必须增加真正依赖跨时间证据的任务；Endoscapes 的目标帧 CVS 评估不能独自支撑这个主张。历史时刻满足某条件，也不能自动说明当前时刻满足。

数据：Endoscapes 用于可清楚定义的条件级校准；SurgCoT 的多事件／转换任务用于长时序验证；MedHorizon 用于外部泛化。只有在确认标注覆盖足够完整时，才开展“某事件全程未发生”任务。稀疏标注下没有记录事件，不等于事件不存在。

指标：risk–coverage 曲线、固定回答覆盖率下的错误率、错误肯定率、事件漏检率、证据成本、校准误差、换术式／来源后的风险变化。允许拒答的方法必须在相同覆盖率下比較；不能仅靠多拒答降低错误。

最小验证：同一预算下比较固定补看、自报置信度、共享结构化检查+固定补看、条件收益驱动补看、加入完整策略风险校准。若条件动作选择无法超过最好的固定策略，或所有收益只来自拒答，本方案的方法贡献不足。

这一方向有较清晰的医学意义和潜在理论问题，但校准假设、标注质量和域偏移是主要难点。现有证据不足以宣称真实临床风险被控制；实验结论应严格落在指定数据分布和预测任务上。

**八、P5：可核验的多证据课程驱动自进化**

暂定英文题目：**Verifiable Multi-Evidence Curricula for Self-Evolving Video Agents**。

研究问题：能否减少对人工问答的依赖，同时避免 Agent 自己出题、自己验证、自己强化错误？

拟议方法：从训练视频建立带来源帧和时间段的事件候选；生成需要两个以上事件或视角才能区分答案的任务；用独立视觉核验与可计算的时间关系筛选；根据学生学习进展选择下一批题，而不是单纯选择最难题；更新后生成新轨迹，再扩展任务结构。

应区分可计算的时间逻辑与需要视觉语义判断的部分。对于已有可靠事件标签的训练视频，可以精确核验先后、持续时间和组合约束；对无标注视频，事件识别仍有误差，跨模型一致也不能视为真值，因此需要抽样人工审核。医学上优先生成可观察的事件与关系问题，不自动把视觉事件推成诊断或因果结论。

EvoGround 已从无标注视频生成 query–moment 对；SESA 已把出题与技能记忆共同演化。本方案的潜在差别是**多证据依赖的任务构造、核验及其课程效用**，并要验证其迁移到人类设计的问题。仅把 proposer–solver 换到 VideoSpy 上不够。[EvoGround](https://arxiv.org/abs/2605.13803)、[SESA](https://arxiv.org/abs/2607.29468)。

最小实验：固定同一批训练视频和生成预算，比较随机任务、难度优先、学习进展优先和多证据可核验课程。验证自动题错误率、证据依赖性及人工测试上的迁移，而不是只看自产题成绩。保留 question-only、单帧、时间顺序打乱等对照。

风险：验证器与生成器共享偏差；“多证据”题可能被语言先验直接解答；合成分布与自然提问存在差异。因此这是高风险储备方向，优先级低于 P1/P3。

|---|---|---|
| 本地 MedVidBench 适配 | 代码区分公开 TrainVal 来源与隐藏 leaderboard 来源；此工作目录未见实际数据和运行产物 | 可最快复用代码；启动前恢复实际数据及 manifest，按原视频检查划分 |

| [Endoscapes](https://github.com/CAMMA-public/Endoscapes) | 官方仓库提供 CVS、检测和分割标注说明与下载入口 | P4 的条件级试验；不能替代完整长视频问答；核实具体下载入口和使用条件 |

| [MedClawBench](https://fyycs.github.io/medclaw/) | SVU 测试部分有公开上游；神经外科录像尚未公开，代码页面也标注待开放 | 可研究其方法与可访问子集；不把完整私有录像作为可立即获取资源 |

医学范围建议先限定为手术／内镜长视频。现有工具和 benchmark 与这些场景的契合度较高；超声、病理和放射学视频的观察需求不同，初期全部加入会使方法贡献难以归因。这是基于当前项目条件的研究取舍，不代表其他医学方向价值更低。

**十、共同实验原则与前两周诊断计划**

正式研究至少分开训练、调参／候选筛选、最终测试；P4 还需明确校准数据的角色。按患者、原始手术、来源视频划分，再生成 QA 和轨迹。同一原始视频的不同裁剪以及跨数据集转载，仍可能造成泄漏，需要来源 ID、时间范围和可用时的近重复检测。没有患者元数据时只能报告视频级隔离，不能声称患者级隔离。

工具输出中的检索事实必须保留病例来源约束；可迁移策略与病例事实分开。事实 Memory 在严格视频不重叠划分下可能没有可检索内容，这不是程序错误，也不能因此放宽到把其他病例的事实当当前视频证据。

成本同时记录训练教师调用、生成失败轨迹、反思、候选验证、参数更新，以及推理中的所有模型调用、视觉 token／像素量、抽帧解码与端到端延迟。固定框架里的工具调用次数不等于相同计算预算。

标注充足时同时报告答案与证据指标。时间窗口覆盖并不保证模型真正利用了证据；轨迹中的推理文本也不是过程正确性的真值。采用自动指标、来源核验和一小部分盲评人工检查的组合，避免同一个教师独立承担出题、标注、评分和最终裁决。

以下时间表假设数据可访问、模型服务已就绪，是工作量估计：

| 时间 | 任务 | 决策依据 |
|---|---|---|
| 第 1–2 天 | 恢复数据与模型配置，检查划分和轨迹可恢复性；复现小样本基础运行 | 当前瓶颈在搜索、感知还是推理？ |
| 第 3–5 天 | P1 分支回放诊断：原动作、重答、固定补看、候选补看 | 是否存在可预测的观察动作收益差异？ |
| 第 6–8 天 | P3 教师视野与学生观察匹配诊断 | 信息条件不匹配是否真实影响执行？ |
| 第 9–12 天 | 小规模策略／LoRA 试验；加入数据量和成本匹配对照 | 收益能否在新视频保留？ |
| 第 13–14 天 | 失败案例与结果评审，确定一条主线 | 继续、缩小问题，或否定假设 |

训练资源未知，因此暂不承诺特定 GPU 数或费用。优先训练小型决策模型并固定视觉工具，以降低显存要求；端到端视频 VLM、长序列 RL 和多路 LoRA 更新属于后续独立预算。确定硬件后，再根据实测序列长度、吞吐和分支数估算完整成本。

研究判断：P1 的优势是与现有自进化实现衔接最紧；P3 的优势是把医学轨迹蒸馏收敛为一个一般的部分可观测学习问题；P4 的优势是医学任务有明确的错误类型和证据要求。P2/P5 更有扩展空间，但也更容易落入已有方法组合，适合等诊断结果支持后再投入。
